# 📱 Pokedex - Proyecto Final

## 📖 Descripción
Pokedex es una aplicación móvil desarrollada en Android Studio que permite a los usuarios visualizar diferentes Pokémon junto con sus descripciones e información básica.  

La aplicación fue creada como proyecto final con el objetivo de aplicar conocimientos de desarrollo móvil, diseño de interfaces y consumo/visualización de información dentro de una aplicación Android.

## 🎯 Objetivo del Proyecto
El objetivo principal de esta aplicación es ofrecer una experiencia sencilla e interactiva para consultar información de Pokémon, mientras se ponen en práctica los conocimientos adquiridos durante el semestre en el desarrollo de aplicaciones móviles.
